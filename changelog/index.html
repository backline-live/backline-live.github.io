Changelog

Every release, newest first.

1.3.2

2026-11-25
  • Fixedin a trial, the program label said 1920×1080 while the output is capped at 1280×720: it now shows what is really rendered ("1280×720 · trial").
  • CheckedWindows (TouchDesigner 2025.33230): install from the ZIP, trial key, every part runs at 60 fps.

1.3.1

2026-11-25
  • Fixedwith an AV (or Lights Control) key, the other part's panels still showed on PERFORM: now its panels go too, like a part that isn't in the project.
  • Addedbuttons where the page showed links or text you couldn't click or copy in TouchDesigner's window: the licence screen (Paste key, Trial / buy, My keys, Copy support email), Setup › License (Open portal, Copy link) and the "not in your licence" banner (Copy email). Links open in your normal browser.
  • Fixedthe licence banner squeezed its buttons on a narrow window.

1.3.0

2026-11-25
  • Addedpacks. AV (Core + AV + MIDI, €40), Lights Control (Core + LIGHTS + MIDI, €40), Full (all, €60). Your key's pack decides which parts run; a part outside it stays off (AV black / no DMX) and its screens are hidden, with a banner. Setup › Show › License shows the pack. Keys from before (and the trial) cover every part.

1.2.0

2026-11-25
  • Changeda key is needed. Without one (or after a trial key ends) Backline shows only its licence screen: paste a key and Activate. The program output is black, no DMX goes out, controllers are ignored. Your project and show data are untouched.
  • Changedthe free trial key (14 days) runs Backline with limits: "Backline · trial" watermark on the program, program at most 1280×720, LIGHTS plays 8 fixtures on one universe, show files and snapshots can't be saved (MIDI maps, the patch, layouts and autosave still save). A TRIAL tag on the scene / effect tiles and a banner say so.
  • Changeda paid licence that fails at start (offline past 30 days, clock, revoked) runs as a trial, it never locks: fix it with Check now.

1.1.0

2026-11-25
  • Changedthe free trial is a key. Order the free trial on Polar: its key works like a licence key for 14 days (Setup › Show › License: "trial key · N days left"). Without a key the program shows the "Backline · unlicensed" watermark from the first start (it said "BETA"). Everything keeps working, the output never stops.

1.0.1

2026-11-25
  • Fixeddemo/demo.tox did nothing when dragged in (an old build without its installer). Now it adds 2 scenes, 2 effects, 8 looks and 2 light effects to your folders and removes itself.

1.0.0

2026-11-25Backline, first paid release
  • Addedlicence. 14-day trial from the first start on a computer, then a licence key from your Polar order (Setup › Show › License: Activate, Check now, Deactivate this computer); 2 computers per licence; 30 days offline; checked only at project start, never during a show. Unlicensed = banner + watermark, nothing stops.
  • AddedLIGHTS ships (fixtures from the Open Fixture Library, looks × groups, Art-Net / sACN / ENTTEC).
  • Changedthe product is called Backline. Your licence covers every build released within a year of your purchase.

0.3.2

2026-11-24artist beta
  • Fixedvelocity pads and keys hit softly were ignored: TD's MIDI templates only let velocity 127 in, and our engine counted a press only from velocity 64. Now every button, pad and key passes what the controller sends: any hit is a press, actions fire, envelopes scale with the velocity, the MIDI screen lights a button by its velocity. On / off buttons (LCXL, APC mini) behave as before. Controllers you saved yourself get the new template on their next Save in Setup › Controllers.
  • Addedlibrary import keeps everything the library knows: pads (velocity), keyboards (one button per key, drawn as a piano), and the numbers the library marks unverified (amber dot + "check" tag). Capture confirms them: a control heard with its exact number loses its mark. Re-import a library controller to get this.
  • AddedSetup › Controllers by hand: + Knob / Fader / Button, + Keys (from - to), drag to move, corner to resize, Free layout (place controls anywhere, set the panel size) for controllers made from scratch.
  • FixedSetup › Controllers could stop answering in TouchDesigner's window after a reconnect; new controls were placed over a faceplate's bottom row; the check tag drew over the row above.
  • Formatsunchanged (show file 3, MIDI map 1).

0.3.1

2026-11-24artist beta
  • Fixedscreen layout edits were saved into the AV Infrastructure folder's demo files instead of your show folder (in a project outside the folder). If git status in your clone shows demo/show/core/layouts.json changed, run git checkout -- demo/show there before git pull.
  • FixedMIDI screen: small buttons of library controllers (e.g. APC40 MK2 clip grid) drew as thin bars or dots; their LED lights are sized to the button.
  • Fixedthe troubleshooting log names the version and parts even when Core starts before it finds its folder.

0.3.0

2026-11-24artist beta
  • Addedcontrollers per project: the MIDI bar has ONE Controllers button (add from the list, remove with two clicks); a new show starts with the computer keyboard only.
  • AddedSetup › Controllers: make or edit a MIDI controller (Capture its knobs / faders / buttons, name them, place them, LEDs, default map) or import one of 27 models from the open-audiovisual library (MIT), drawn as its real faceplate. Saved controllers ship with the folder. Akai LPD8 MK2 included.
  • AddedMore › Report a problem…: write what happened, get one zip (logs of the last sessions, errors, setup, optionally your show files) to email. Nothing is sent by the app. A session log runs in <show>/cache/log/.
  • Addeda control can have its own MIDI channel (e.g. LPD8 pads on 10, knobs on 1).
  • ChangedSetup › Controllers › MIDI port: ports plugged in now and ports only remembered are shown apart.
  • ChangedMore › Look on every screen; sheets close with Esc or a click outside; the clicked panel's title turns blue (keyboard scope).
  • Fixedstatus bar LOAD showed the frame length (16.7 ms at 60 fps even when idle): now TD's real work per frame.
  • Fixedthe TouchDesigner window no longer freezes after a display / zoom change (UI size is done in the page).
  • Licencecommercial use allowed (your own shows and client work); still no changes and no sharing.
  • Formatsunchanged (show file 3, MIDI map 1).

0.2.0

2026-11-24artist beta
  • Addedinstall once, use in any project: clone the repo, drag core.tox + the parts you need into any TouchDesigner project (each part finds the repo by itself).
  • AddedSetup › Show folder › Change… (pick / make the show folder) and Import from… (copy MIDI maps, rig, light presets, layouts or snapshots from another show; replaced files kept in backup/).
  • AddedOpen Fixture Library fixtures are downloaded the first time you add one (lights/library/local/ in the cloned folder; nothing is written outside it or your project).
  • Addeddemo/demo.tox: drag it in and its scenes / effects are added to your folders, then it removes itself (names you already have are kept). This release: Core + AV + MIDI (LIGHTS comes later).
  • Fixedthe TouchDesigner UI window at any size, on any display and in fullscreen: no more black window, the mouse hits where you point, live previews stay in their boxes; works with the Non-Commercial licence; fullscreen on a MacBook with a notch keeps the top bar below it.
  • Fixednumber keys 1-9 / Shift+1-9 (cue scene / effect) in the TouchDesigner window.
  • Fixeda controller switched off no longer talks to another controller's port in a new project; effects get the scene picture in a new project; Core asks for the folder once.
  • Changeda new show starts empty: nothing mapped on the controllers (MIDI window › Default loads the shipped map), no fixtures; empty banks say what to put where.
  • Changedthe page shows only the parts in the project (screens, Setup tabs, MIDI strip / map button).
  • Formatsunchanged (show file 3, MIDI map 1).
FormatsOld show files upgrade by themselves; newer ones are refused. Latest: unchanged (show file 3, MIDI map 1).
