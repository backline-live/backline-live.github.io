Changelog

Every release, newest first.

1.4.1

2026-11-25controllers editor, LEDs for any controller
  • Changedthe product is now called ziptie (was Backline). Your key keeps working. New site address: https://ziptie-live.github.io.
  • ChangedPERFORM's bottom strip no longer shows the 8 focus knobs of AV / LIGHTS (controllers, last control, Map last and From TD stay). The focus knobs still work from your controller.
  • AddedSetup › Rig › View ▾ › Background: the 3D view's background from black to mid grey.
  • Changedthe demo's effects are clearly visible now: effect0 = horizontal lines scrolling up / down, effect1 = vertical lines scrolling sideways; controls Speed, Color, Lines, Width, Opacity. No text labels on the demo scenes and effects any more.
  • Fixedthe trial banner mentioned "8 fixtures" although the trial has no LIGHTS.
  • AddedSetup › Controllers › Record as auto / knobs / faders: sliders can be recorded as faders (a MIDI CC doesn't say which it is); moving a recorded control again with another choice re-types it. The last message heard (channel, number, value) shows next to Record, and the selected control's live value in the Control section.
  • AddedSetup › Controllers: pages (the same controls on another channel, e.g. a template: recording asks once "New page?"), select several (Shift / Cmd-click, box), drag a group, drop on another control to swap, arrow keys to nudge, Delete to remove, Undo (Cmd+Z). A moved control flashes with a value bar, and its LED lights on the controller (buttons of a new controller too). Page tabs: a new page opens blank and fills as you move its controls; the drawing follows the page the MIDI comes from and the toolbar names it. Values are drawn like the control (a knob's pointer, a fader's fill, a lit button), smoothly even with several controls moving at once. A control that becomes a fader / button / knob is renamed F.. / B.. / K.. (names you typed stay; only on a controller not saved yet, a saved one's names are in your maps). On a Launch Control XL, pressing User / Factory switches the page shown at once, and while recording its knob and button LEDs light green as you move them, then stay dim green (recorded). Copy LEDs from a controller ziptie knows on the same port (one click: driver, LED numbers), and a Test button per control's LED.
  • Addedan LED assistant for any controller (Setup › Controllers › LEDs): select a button, Find LED lights the most likely way and waits: Next ▸ / ◂ Back try other ways at your pace, It lit! takes it, Same rule for all buttons, then a colour slider shows each value live on the LED and use as off / on (or red / green / yellow) stores it.
  • Addeddelete a controller you made (Setup › Controllers list, ✕ then Delete?): it leaves the project and its folder moves to the show folder's backup/controllers. The controllers that come with ziptie can't be deleted.
  • FixedLEDs of a controller's page 2 (LCXL factory template) stayed dark: Copy LEDs from the LCXL now also turns on its template tracking and links each page to its template. Saving a controller rebuilds it from the profile just written (it could use a cached older one).
  • FixedSetup › MIDI: the drawing now shows the page of the control just moved (any controller with pages), and the page tabs no longer wrap ("Page 2" on two lines).
  • Fixedcontrols moved while Record was off were recorded when Record was turned on (old messages handed over at the start): Record now starts clean.
  • Fixedrecording a controller that is also added to the show drove the show and its LEDs fought the editor's: while Record / Find LED runs on a port, controllers on that port are held (their LEDs off, nothing sent to the show).
  • Fixedthe MIDI screen's LED palette looked broken on a controller without LED settings: it now says so and where to set them (Setup › Controllers › LEDs).
  • Fixedthe editor's live value could stop short of the real one (a fader at max showed 118).
  • Fixedafter an update, TouchDesigner's window could keep showing the old page (its built-in browser reused stored files): page files are now served under a version stamp and never stored, and the window's address follows the version.

1.4.0

2026-11-25AV pack; the release repo starts fresh here
  • Changedziptie ships as the AV pack (Core + AV + MIDI). LIGHTS is not in the release yet; it will come back as its own pack (and Full) when it is ready. The free trial key covers AV + MIDI.
  • Changedan unsaved project no longer creates shows/NewProject next to TouchDesigner's default folder: its show data waits in a temporary folder (the page asks you to save), then moves next to the .toe on the first save; Save As copies it to the new name. A show folder you picked yourself is never moved.

0.3.2

2026-11-24artist beta
  • Fixedvelocity pads and keys hit softly were ignored: TD's MIDI templates only let velocity 127 in, and our engine counted a press only from velocity 64. Now every button, pad and key passes what the controller sends: any hit is a press, actions fire, envelopes scale with the velocity, the MIDI screen lights a button by its velocity. On / off buttons (LCXL, APC mini) behave as before. Controllers you saved yourself get the new template on their next Save in Setup › Controllers.
  • Addedlibrary import keeps everything the library knows: pads (velocity), keyboards (one button per key, drawn as a piano), and the numbers the library marks unverified (amber dot + "check" tag). Capture confirms them: a control heard with its exact number loses its mark. Re-import a library controller to get this.
  • AddedSetup › Controllers by hand: + Knob / Fader / Button, + Keys (from - to), drag to move, corner to resize, Free layout (place controls anywhere, set the panel size) for controllers made from scratch.
  • FixedSetup › Controllers could stop answering in TouchDesigner's window after a reconnect; new controls were placed over a faceplate's bottom row; the check tag drew over the row above.
  • Formatsunchanged (show file 3, MIDI map 1).

  • FixedMIDI screen: small buttons of library controllers (e.g. APC40 MK2 clip grid) drew as thin bars or dots; their LED lights are sized to the button.
  • Fixedthe troubleshooting log names the version and parts even when Core starts before it finds its folder.

0.3.0

2026-11-24artist beta
  • Addedcontrollers per project: the MIDI bar has ONE Controllers button (add from the list, remove with two clicks); a new show starts with the computer keyboard only.
  • AddedSetup › Controllers: make or edit a MIDI controller (Capture its knobs / faders / buttons, name them, place them, LEDs, default map) or import one of 27 models from the open-audiovisual library (MIT), drawn as its real faceplate. Saved controllers ship with the folder. Akai LPD8 MK2 included.
  • AddedMore › Report a problem…: write what happened, get one zip (logs of the last sessions, errors, setup, optionally your show files) to email. Nothing is sent by the app. A session log runs in <show>/cache/log/.
  • Addeda control can have its own MIDI channel (e.g. LPD8 pads on 10, knobs on 1).
  • ChangedSetup › Controllers › MIDI port: ports plugged in now and ports only remembered are shown apart.
  • ChangedMore › Look on every screen; sheets close with Esc or a click outside; the clicked panel's title turns blue (keyboard scope).
  • Fixedstatus bar LOAD showed the frame length (16.7 ms at 60 fps even when idle): now TD's real work per frame.
  • Fixedthe TouchDesigner window no longer freezes after a display / zoom change (UI size is done in the page).
  • Licencecommercial use allowed (your own shows and client work); still no changes and no sharing.
  • Formatsunchanged (show file 3, MIDI map 1).
