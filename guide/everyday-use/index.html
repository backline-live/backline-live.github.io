Everyday use

  • Open the UI: Core par Openui (TD window) or http://localhost:9980 in a browser. The top bar's screen buttons: Perform (visuals left, lights right: what you play), AV, Lights (one side full width), MIDI (the MIDI window), Setup (tabs: Visuals, Looks, Rig = patch / library / groups / 3D stage, MIDI = the mapping editor, Controllers = make / edit a MIDI controller, Outputs = DMX + displays, Show = files / recovery / version). /?parts=lights = only LIGHTS' panels (also av, midi). Details: UI.md §1.
  • Visuals (AV side): click a scene tile = cue to preview; AUTO / T-bar / CUT take it to program. Space = GO, Enter = CUT, E / Shift+E = effect GO / CUT, B = FTB, Shift+B = blackout, F = freeze, 1-9 = cue (keys reach AV while an AV panel has the key scope: click it; its title turns blue).
  • Lights (LIGHTS side, LIGHTS.md §13.1): the looks × groups matrix: tap a cell = cue that look on that group (green), double-tap = take now; GO / T-bar / CUT fade every cued group (red = on air). The 2D rig map shows PVW (after the next GO) and PGM (the fixtures now). Live keys: FLASH / SOLO (hold) / KILL per group, STROBE / BLINDER / BLACK (hold), Rate 1/2 · 1 · 2, effect chips + amount, grand + group masters. Map APC (click twice) makes the APC Mini's grid the matrix.
  • Snapshots (top bar, 8 slots): an empty slot, click twice = capture every AV + LIGHTS value; click = recall (morph seconds in the box next to them).
  • Blackout / Panic (top bar): blackout of every part (click toggles); Panic = every part safe, click again to release.
  • Search / command palette (top bar button or Ctrl/Cmd+K): type part of a name ("tap", "blackout", "scene go"); Enter runs the action, Shift+Enter jumps to its control (it flashes). Locked: nothing runs from it (except Panic). Needs a click on a panel first when used inside TD's window.
  • MIDI: plug a controller in and switch it ON (MIDI window chip). A new show maps nothing: map what you want (below), or load the controller's shipped map with MIDI window › Default (hold 1.5 s; Undo works). The shipped map: LCXL knobs = the focused scene / look's knobs, faders = T-bars + masters, buttons = cue / GO / CUT / blackout, Mute = AV <-> LIGHTS page; APC grid = scenes + effects (AV page) or the looks x groups matrix (LIGHTS page), faders = T-bars / focus knobs / group masters. Your own links: right-click any control → Learn → move a knob (the first change writes the map into the show folder). From TouchDesigner: MIDI window Learn from TD (or From TD on PERFORM's MIDI strip), change the par in TD's own parameter window (select its COMP), move a knob: mapped. Map last: move an unmapped knob, touch a control on the page (or change a par in TD), click Map last on the strip. The strip also shows what the 8 focus knobs play now. Default in the MIDI window (click twice) puts the default back (old map kept as .before_default, Undo works). Layouts: MIDI.md §1c.
  • Lock (top bar): locks every page and remote (MIDI and TD stay live). Hold to unlock.
  • Tempo: one clock for every part (top bar: BPM = click it, type the tempo, Enter (Esc cancels; read-only while Link drives it), Tap, Link; Core page Clock: Bpm, Tap, ½ / ×2, Ableton Link). Light looks / effects follow it (the engine's clock). With Link on and a peer, AV's GO waits for the next bar / beat (AV page Sync: Quantize GO, fade unit seconds / beats); GO again = now, CUT is never delayed.
  • Show files: top bar Show → Save (every part's state under a name) / Load (click twice; refused while locked). A show saved by an older release opens (it is upgraded); one saved by a NEWER release is refused with a message and nothing changes. The release you run: VER at the right of the status bar.
  • Crash recovery: every 5 s Core saves every part's state to <show>/cache/core_recover.json. After a TD restart a banner offers Restore / Dismiss; nothing happens by itself.
  • Not in the beta (the code stays, not on the fixed screens, after the artists' feedback, docs/DESIGN.md §3): Core's cue list (panel Cues, <show>/cues.json; on Setup › Show for snapshot editing), AV's setlist (and its Core's LFO / beat sources (§3 "Sources"), the phone / tablet remote (Show → Pair, /remote, UI.md §4; Remote access is off by default).

Set up the rig (Setup › Rig)

Top bar Setup → tab Rig. Rig edits need an admin page and Lock off; Undo / Redo sit in the rig bar (or Ctrl Z with the stage focused). Details: LIGHTS.md §12.

  • The screen: rig bar on top (what the rig is: fixtures · positions · groups · universes · channels, and a ⚠ problems chip when something is wrong); left Library | Groups; centre the 3D stage with its tools floating on it, over a drawer Patch | DMX | Problems (▾ Hide folds it, the stage gets the room); right the Outliner (every position with its fixtures) over Properties (whatever is selected).
  • Hang positions first (optional): the stage's ＋ button → Truss / Pipe / Boom / Floor, appears at the view centre. Move it with G (or the gizmo, W), name / kind / length in Properties › Position.
  • Patch fixtures: Library → type in the search box or pick a type chip (nothing typed = the types already in the rig + your own) → click a type. Its card: Mode, Count, Start address (empty = next free, shown greyed), First FID (empty = first free), Group (an existing one ▾ or a new name), Hang on (default: the selected position). The line under it says what will happen: FIDs, the address range, and in red a clash or "past 512" (Add is off then). Add N to the rig → they are added and selected. Or drag a type from the list onto the stage: they land on the truss / pipe / boom under the cursor, spread along it (or on the floor). Not in the library: + New type (its channel list) or Import GDTF….
  • Fix the patch: drawer Patch = the fixture sheet (click a cell, type, Enter; ✕ twice = unpatch), or select fixtures and use Properties › Fixture / Patch: several selected with different values show mixed (empty field); typing sets them all; FID / start address on several = the first, the rest follow in FID order. These field edits are not on Undo yet: note the old value first.
  • Group and order: tab Groups → select fixtures (stage, Outliner or Select ▾) → + Group from selection (type a name) or Add selection to ▾. The chips in a group are its order = how looks and effects spread over it (the first chip = index 0): drag a chip, or Sort ▾ by X (left → right on stage) / by FID / Reverse. Click a group's header = select the group.
  • Place: in the stage: G move / R rotate (then X Y Z, a number, Enter), Shift D duplicate, X delete; Option + drag orbit, Shift + drag pan, two fingers zoom; F frame the selection. Exact values: Properties › Place (X Y Z + rotation, Absolute or Relative, Hung on ▾). Several at once: Properties › Arrange (Align, Distribute, Mirror, Array…, Duplicate, Delete twice). Drag a fixture row in the Outliner onto a position = hang it there.
  • Check: the ⚠ chip / drawer Problems lists address overlaps, addresses past 512, fixtures with no group and missing definitions, each with its fix (Move FID n to next free, Add to ▾, Select / Delete). The same marks show as ⚠ and red addresses in the Outliner. DMX tab = every channel of a universe as a bar (Advanced = numbers); Highlight (H) puts the selected fixtures at full open white to find them on the real rig.
  • Save: the rig is written to <show>/lights/patch.tsv + rig.tsv by itself; save the .toe too.

Something went wrong? (More › Report a problem…)

Write what happened and what you did just before, click Make report. It saves one zip in your show folder › cache/reports/ (Show in folder opens it): the logs of the last sessions, the project's errors, versions and this computer's setup, plus (switch on) the show's text files (MIDI maps, rig, cues, layouts; no media). Nothing is sent anywhere: attach the zip to an email to Matteo. The log runs all the time (cache/log/, one file per session, the last 10 kept), so make the report soon after the problem, before restarting TD many times.
