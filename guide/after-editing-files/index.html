After editing files

TD DATs are synced to the files (syncfile on); edit them in any editor.

  • web files (*/web/, shared/web/): refresh the page (TD window: Core par Reloadui).
  • an extension's .py: pulse Re-init Extensions on that COMP (op('/project1/av').par.reinitextensions.pulse()).
  • a new Python module: (1) write the file, (2) create its Text DAT in TD (file = the .py, Sync to File on), (3) only then save the file that imports it. Wrong order = the extension stops loading.
  • a file TD loads moved: add it to tools/migrate_paths.py MOVES and run migrate() in the .toe.
  • Save the .toe yourself (Cmd+S) when TD-side changes should stay.
