The big picture

TouchDesigner project (any folder: the parts link to the cloned repo, §0)
 ├─ /project1/core      CORE: lock / panic, clock (tap, Link), show folder + show files + crash recovery,
 │                      pairing, layouts, THE page :9980 (every part's panels) and THE TD window (par Openui)
 ├─ /project1/av        AV CTRL (a part): scene / effect A-B buses, fades, master, user modules
 ├─ /project1/lights    LIGHTS (a part): fixtures, patch, rig, 3D stage + looks_engine (looks -> DMX out)
 ├─ /project1/midi      MIDI CTRL (a part): controllers -> Core ids (page maps), pickup, LEDs
 ├─ /project1/scenes    your scenes (one COMP each, auto-discovered)
 ├─ /project1/effects   your effects (one COMP each)
 ├─ /project1/looks     your light looks (one COMP each, out1 CHOP)
 ├─ /project1/lightfx   your light effects (CHOP in -> CHOP out)
 └─ /project1/modules   extra AV panels (any COMP with out1 + custom pars, or tagged avmodule)

Parts never call each other: each publishes actions (GO, cue buttons, blackout ...), targets (faders, parameters) and textures (program, stage) to Core, and uses what Core offers. A missing part only hides its panels. Ports: Core 9980 (the page), AV 9985, MIDI 9981, LIGHTS 9982 (data only; their root URLs open Core's page).

Show data lives in a show folder, not in the product: Core par Showfolder (page Show) = shows/<name>/ with lights/ (patch.tsv, rig.tsv), midi/<controller>/ (av_map.tsv, lights_map.tsv; missing = nothing mapped: MIDI window › Default (hold) loads the controller's shipped map), core/layouts.json, the show files *.json and cache/ (recovery, thumbnails, pairing tokens; not in git). A new show starts empty (screen layouts + the stage floor only; nothing mapped, no fixtures). Change it from the page: Setup › Show › Show folder › Change… (the OS folder dialog on the TD machine; you can make a new folder there): an empty folder becomes a new show, a folder with files is that show; every part reloads its files at once. Import from… copies chosen pieces of ANOTHER show into this one (MIDI maps · rig & fixtures · light presets & cues · screen layouts · snapshots); the files it replaces are kept in backup/<date_time>/. One project = one show folder (do not share one between projects: import instead). Both refused while locked. Typing a new Showfolder par by hand still applies only when the project is reopened.
