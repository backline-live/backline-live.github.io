Playing a show

The page (TD window or http://localhost:9980). The top bar has the screens: Perform (what you play), MIDI (the mapping window) and Setup (tabs Visuals, MIDI, Controllers, Outputs, Show). Right side: Blackout, Panic, Lock and More (Search, Edit layout, Show files, Look, Fullscreen, Shortcuts).

Visuals

  • Click a scene tile = put it on preview; double-click = take it to program at once. AUTO (or GO) fades preview to program in the fade time; the T-bar fades by hand; CUT switches at once. Effects work the same way on their own bus.
  • Keys (click an AV panel first; its title turns blue): Space = GO, Enter = CUT, E / Shift+E = effect GO / CUT, B = fade to black, Shift+B = blackout, F = freeze, 1-9 = cue scene 1-9.
  • Parameters: the custom pars of the scene / effect you select. Sliders move only when you grab their knob (no jumps); click a number to type a value.
  • Master: level, fade to black, blackout, freeze.

Safety

  • Blackout: every part goes dark (click toggles).
  • Panic: hold 0.5 s. Every part goes to safe, the page and controllers can't trigger anything; hold again to release.
  • Lock: click to lock the page (and paired devices); hold to unlock. MIDI and TouchDesigner stay live.

Tempo: one clock for everything. Top bar BPM (click, type, Enter), Tap, Link (Ableton Link). With Link on and a peer, AV's GO waits for the next bar / beat (AV › Sync: quantise GO, fade unit seconds or beats); GO again = now; CUT is never delayed.

Snapshots (top bar, 8 slots): click an empty slot twice = capture every value now; click a slot = recall it (morph seconds in the box next to the slots).

Search (top bar or Ctrl/Cmd+K): type part of a name ("blackout", "scene go"). Enter runs the action, Shift+Enter jumps to its control (it flashes). In TD's window click a panel first so the page has the keyboard.

Show files: More › Show files › Save (every part's state under a name) / Load (click twice; refused while locked). A show saved by an older ziptie opens (it is upgraded); one saved by a newer release is refused with a message and nothing changes. The version you run: VER at the right of the status bar.

Crash recovery: Core saves the state every 5 s. After TouchDesigner restarts, a banner offers Restore or Dismiss; nothing is applied by itself.

Layouts: More › Edit layout changes the panels of the screen you are on (drag seams, add / remove panels); Reset screen goes back to the built-in layout. Look sets theme, accent and UI size (Auto fits the window).
