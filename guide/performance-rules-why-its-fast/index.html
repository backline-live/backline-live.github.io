Performance rules (why it's fast)

  • Only the A/B bus COMPs cook (allowCooking); everything else is frozen.
  • Core's TD window paints live textures straight into the page (no JPEG); browsers get JPEG previews only while a visible page asks for them (~1-2 ms TD time per frame).
  • State goes to the pages as deltas; MIDI rows cost ~0 when idle.
  • Measure with the status bar, not while an MCP / agent session is connected (it adds load).
