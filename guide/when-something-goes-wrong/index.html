When something goes wrong

Licence messages (Setup › Show › License):

  • every computer of this licence is in use: Deactivate on the old computer, or free it in the customer portal.
  • licence key not found, revoked…: copy the key again from the order email; a refunded key stops working.
  • not checked online for N days: connect to the internet, then Check now (or reopen the project).
  • clock set back: set the computer's date right, then Check now.
  • updates ended on …: your year of updates is over; releases from before that date keep working (download that release, or git checkout its tag).
  • licence expired on …: the trial key ended: buy, then Activate the new key.

Report a problem (More › Report a problem…): write what happened and what you did just before, click Make report. It saves one zip in the show folder's cache/reports/ (Show in folder opens it): the logs of the last sessions, the project's errors, versions and this computer's setup, plus (if you tick it) the show's text files. Nothing is sent anywhere: email the zip to ma.codeeee@gmail.com. Make it soon after the problem: the last 10 sessions are kept.

Common things

  • The page in TD's window is black except the live pictures: the Web Render TOP in core/ui is bypassed: select it and press Cmd/Ctrl+B again.
  • A controller does nothing: is its chip ON in the MIDI screen? Is the control mapped on the page the controller is on (AV or LIGHTS)? MIDI screen › Check lists what is wrong.
  • A knob moves nothing: it waits for pickup: turn it through the current value.
  • A par of my scene does not show up: it needs a custom page that is not called Setup…, and a plain value (no expression).
  • Frame drops: the status bar shows fps and drops; a scene's cook time shows on its tile. Measure without other heavy apps or agent tools connected to TD.
