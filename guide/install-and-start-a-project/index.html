Install and start a project

What you need: TouchDesigner 2025 (macOS or Windows), a ziptie licence key or a free trial key.

Get the files (once per computer):

  1. After the purchase (or the free trial) open the order email and press Access purchase: that is your Polar customer portal. Press Connect GitHub there: GitHub invites your account to the private ziptie repository. Accept the invitation (GitHub email, or github.com/notifications).
  2. On the repository page open Releases, download ziptie-<version>.zip and unzip it into a folder that stays (for example Documents/ziptie, not Downloads). Or git clone the repository into such a folder.
  3. Your licence key is in the same portal and in the order email (the trial gets a key too, valid 14 days).

A new project (anywhere on the disk, nothing is copied into it):

  1. Make a new TouchDesigner project and save it where you want it.
  2. Drag from the ziptie folder into /project1: first core/core.tox, then av/av.tox (visuals) and midi_ctrl/midi.tox (controllers, optional). Keep their names (core, av, midi).
  3. The first time, Core asks where the ziptie folder is (a folder dialog): pick it. The answer is saved in the project (Core par Repofolder). Moved the folder later? Set Repofolder again, or clear it and Core asks again.
  4. Open the page: pulse the core par Openui (TouchDesigner window) or open http://localhost:9980 in a browser.
  5. Save the project (Cmd+S / Ctrl+S). Until it is saved its show data sits in a temporary folder and the page says so.

Activate your key: the page shows the licence screen until a key is active. Paste the key → Activate (needs the internet once). One key covers 2 computers; every project on a computer uses it.

  • Trial key (14 days): everything works, with a "ziptie · trial" watermark on the program, the program at most 1280×720 and no show-file / snapshot saves (MIDI maps and layouts still save). When it ends, buy and activate the new key.
  • Checked only when the project starts: nothing changes during a show. Offline is fine for 30 days after the last check; then connect once. A paid licence that cannot be checked runs like the trial until fixed: it never locks you out mid-gig.
  • New computer: Setup › Show › License › Deactivate this computer on the old one first, or free it in the customer portal (https://polar.sh/mcode/portal, sign in with your purchase email).

Fill the project:

  • Demo: drag demo/demo.tox into /project1: its scenes and effects are added to your scenes and effects folders (names you already have are skipped) and the demo removes itself.
  • From another project of yours: Setup › Show › Import from… → that project's show folder → tick what to copy (MIDI maps, presets, layouts, snapshots). What it replaces is kept in backup/.
  • Controllers: plug in, switch them ON in the MIDI window, then map (§3).

Updates: download the new ZIP and replace the folder's contents (same place, so your projects keep finding it), or git pull. Every project gets the new code the next time it opens. Check your show before a gig; never update right before one.
