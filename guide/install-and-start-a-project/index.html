Install and start a project

Once per computer (TouchDesigner 2025; tested on macOS, Windows not yet):

  1. Get the files: after the purchase (or the free trial), open the order email and press Access purchase: this is your Polar customer portal. There press Connect GitHub (your own GitHub account): GitHub invites you to the private release repository. Accept the invitation (GitHub email, or github.com/notifications), then git clone the repository into any folder you like (for example ~/Documents/backline). Your licence key is shown in the same portal and in the order email (the free trial gets a key too, valid 14 days). Everything the system writes stays in that folder or in your project: downloaded fixtures and your own fixture types go to lights/library/local/ inside it (not in git).
  2. Updates later: git pull in that folder. Every project gets the new code the next time it opens: check your show before a gig, never update right before one.

A new project (anywhere on the disk, no copying):

  1. New TouchDesigner project, save it where you want it.
  2. Drag the parts you need from the folder into /project1: first core/core.tox, then any of av/av.tox (visuals), lights/lights.tox (fixtures, looks, DMX), midi_ctrl/midi.tox (controllers). Any mix works (only AV, AV + MIDI, only LIGHTS ...); the page shows only what is there. Keep their names (core, av, lights, midi). The first time in a project, Core asks where the AV Infrastructure folder is (OS folder dialog): pick the cloned folder. The answer is saved in the project (Core par Repofolder); the other parts follow Core. Moved the folder? Set Repofolder again (or clear it: Core asks at the next start).
  3. Open the UI: core par Openui (TouchDesigner window) or http://localhost:9980 in a browser.
  4. Save (Cmd+S / Ctrl+S). The project's data goes into its show folder, shows/<project name>/ next to the .toe (Setup › Show › Show folder › Change… to put it elsewhere).

Licence (Setup › Show › panel Show folder · license · version, or the banner's Enter key…): paste the key from your Polar order email into Key → Activate (needs the internet once; a key covers 2 computers, every project on a computer uses it). Without a key Backline does not run: the page shows only the licence screen (paste a key → Activate). The free trial gives a 14-day key: everything works, with limits: a "Backline · trial" watermark on the program, the program at most 1280×720, 8 fixtures on one universe, no show-file / snapshot saves (MIDI maps, the patch and layouts still save). When it ends: buy, and activate the new key. A paid licence that cannot be checked (offline past 30 days, clock wrong) runs like the trial until fixed: it never locks. Checked only when the project starts: nothing changes during a show. Offline up to 30 days is fine (then connect once). New computer: Deactivate this computer on the old one first, or free it in the customer portal (https://polar.sh/mcode/portal, sign in with your purchase email). What the License row may say:

  • every computer of this licence is in use: Deactivate on the old computer, or free it in the customer portal.
  • licence key not found, revoked…: copy the key again from the order email; a refunded key stops working.
  • not checked online for N days: connect to the internet, then Check now (or restart the project).
  • clock set back: set the computer's date right, then Check now with the internet.
  • updates ended on …: your year of updates is over; builds released before that date keep working (git checkout an older tag, e.g. git checkout v1.0.0).
  • licence expired on …: your trial key ended: buy, then Activate the new key.

Anything else: More › Report a problem, then email the zip to ma.codeeee@gmail.com.

What a new project has: empty scenes, effects, modules, looks, lightfx folders (the page says what to put in each), nothing mapped on the controllers, an empty patch. To fill it:

  • Demo: drag demo/demo.tox into /project1: its scenes, effects, looks and light-effect templates are added to your folders (scenes, effects, looks, lightfx; a name you already have is skipped) and the demo removes itself. Demo fixtures: Setup › Show › Import from… → demo/rig_show → Rig & fixtures.
  • From another project of yours: Setup › Show › Import from… → its show folder → tick MIDI maps / rig / presets / layouts / snapshots (what you replace is kept in backup/).
  • Fixtures: Setup › Rig › Library. A fixture of the Open Fixture Library is downloaded the first time you add it (needs internet once; kept in lights/library/local/ of the cloned folder). Example types made for real shows are in demo/fixtures/: copy a maker folder into lights/library/local/custom/ and reopen the project to use it.
  • Controllers: plug in, switch ON in the MIDI window, map with Learn, or hold Default for the shipped map.
