MIDI controllers

Switch it on: plug the controller in, open the MIDI screen and switch its chip ON. The computer keyboard is on by default; hardware starts off. A new show maps nothing.

The shipped map: MIDI screen › Links › Default (hold 1.5 s; Undo works) loads the controller's map:

  • Launch Control XL MK2: knob rows = focus knobs 1-16 (below), sliders = scene T-bar, effect T-bar, master; track focus buttons = cue scenes 1-8, track control buttons = GO, CUT, effect GO / CUT, focus, freeze, FTB, blackout; ◀ ▶ / ▲ ▼ = scene / effect pages.
  • APC Mini MK1: grid rows 1-2 = scenes 1-16 (Shift = take), rows 3-4 = effects 1-16; bottom row = GO, CUT, effect GO / CUT, freeze, tap, FTB, blackout; faders = T-bars, focus knobs 1-6, Master = master.
  • Computer keyboard: 1-4 cue scenes 1-4, 5 GO, 6 CUT, 7 effect 1, 8 FTB.
  • Panic from a controller: hold the learn button (LCXL Record Arm, APC Track 8) for 2 s.

Map your own

  • Learn on the page: right-click any control (touch: long-press) → MIDI learn → move a knob or press a button.
  • MIDI map mode (top bar MIDI map): every mappable control shows a chip; click one, move a knob: mapped. The strip at the bottom shows the last knob moved, where the next learn lands (which controller page), Undo / Redo, and the selected control's range (Min / Max, curve, invert). Chain learns several controls in a row. Esc ends.
  • From TouchDesigner: From TD on PERFORM's MIDI strip (or the MIDI screen's Learn from TD), then change a custom par in TouchDesigner's own parameter window (select its COMP first), then move a knob: mapped.
  • Map last: move an unmapped knob, touch a control on the page (or change a par in TD), press Map last.
  • A mapped knob picks up: it does nothing until it reaches the current value, then follows (no jumps). Its LED says where it stands: green = following, red blinking = the value is elsewhere on air, red dim = not moved yet.

Focus knobs (no mapping per scene): map a knob once to av.focus.1 (.2, … up to 16). Knob k then plays the k-th parameter of the scene on preview, whatever scene that is. Which parameters: those on a custom page named Knobs first (in order), then the other custom pages; pages named Setup… never. Switch what they follow with av.focus.program / av.focus.preview / av.focus.effect (map them to buttons) or by clicking a scene / effect tile. After a switch a knob waits until it reaches the new value. A knob you mapped with Learn wins over a focus row.

Maps: each controller has two pages, AV and LIGHTS (its page button switches: APC Device, LCXL Mute; the LIGHTS page is for the Lights pack). Maps are saved by themselves in the show folder; Links › Save as / Load keep named versions. Renamed a scene or a par? Check (MIDI screen) lists the rows that point nowhere and offers the likely new name in one click.

Your own controller (Setup › Controllers). The LCXL MK2, APC Mini MK1, LPD8 MK2 and the computer keyboard come ready; 27 more models import from the controller library (From the library…). Anything else:

  1. New: type a name, + New, pick its MIDI port under Controller.
  2. Record: press ● Record and move every knob, fader and button once. A knob and a fader send the same kind of message, so switch as to faders before moving the sliders (buttons are found by themselves).
  3. Templates / pages: a controller with templates on another channel (the LCXL's User / Factory): switch template and move a control; ziptie asks "New page?".
  4. Arrange: drag controls on the drawing (Shift / Cmd-click or a box for several, drop one on another to swap, arrow keys nudge). Delete removes the selection; Undo (Cmd / Ctrl+Z) steps back.
  5. LEDs: Copy LEDs from … when ziptie knows a similar controller; otherwise the assistant: select a button, Find LED, Next ▸ until its LED lights, It lit!, Same rule for all buttons, then set the off / on values with the colour slider.
  6. Save, then Add to this project, and map it like any other controller.

While you record, a controller of the show on the same port goes quiet, so nothing on air moves. A controller you made can be deleted (✕, then Delete?); its folder is kept in the show folder's backup/controllers/.
