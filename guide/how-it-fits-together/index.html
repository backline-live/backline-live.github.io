How it fits together

TouchDesigner project (any folder; the parts load their code from the ziptie folder)
 ├─ /project1/core      Core: the page, lock / panic, tempo (tap, Ableton Link), show folder, show files, recovery
 ├─ /project1/av        AV: scene and effect buses (preview / program), fades, master, freeze, user panels
 ├─ /project1/midi      MIDI: controllers → anything the parts publish, pickup (no jumps), LEDs
 ├─ /project1/scenes    your scenes: one COMP each, found by themselves
 ├─ /project1/effects   your effects: one COMP each
 └─ /project1/modules   extra panels: any COMP with an out1 + custom pars
  • Parts never talk to each other: each one publishes actions (buttons: GO, CUT, blackout…) and targets (values: T-bars, master, every custom par of your scenes) to Core. A controller, the page and the search box all reach them the same way, through the same safety checks (lock, panic).
  • Show data lives in the show folder, not in the product: shows/<project name>/ next to your .toe (Core par Showfolder). It holds the MIDI maps (midi/<controller>/), screen layouts (core/layouts.json), show files (*.json) and cache/ (recovery, thumbnails, logs; safe to delete when TD is closed). Setup › Show › Show folder › Change… points the project at another folder: an empty folder becomes a new show, a folder with files is that show. One project = one show folder (to reuse, Import from… instead of sharing).
  • Ports used on this computer: 9980 (the page), 9985 (AV), 9981 (MIDI).
