Thank you.

Your order is done. Polar emails you the receipt. The files and your licence key are in your Polar customer portal.

Next, five steps

  1. In the order email press Access purchase: this opens your Polar customer portal.
  2. In the portal press Connect GitHub and sign in with your own GitHub account. GitHub then invites you to the private release repository.
  3. Accept the invitation (GitHub email, or github.com/notifications), then git clone the repository once per computer.
  4. New TouchDesigner project: drag in core.tox first, then the parts you need. Setup › Show › Licence: paste the key shown in the portal (also in the email) and press Activate.
  5. Play.

Details and screenshots: Guide › Install and start a project.

No email after 15 minutes? Look in spam, then write to support with the address you paid with.
