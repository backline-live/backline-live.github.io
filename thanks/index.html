Thank you.

Your order is done. Polar emails you the receipt and your licence key; GitHub emails you an invitation to the release repository.

Next, five steps

  1. Accept the invitation from GitHub (check spam; it can take a few minutes).
  2. git clone the release repository once per computer.
  3. New TouchDesigner project: drag in core.tox first, then the parts you need.
  4. Setup › Show › Licence: paste the key from the email, press Activate.
  5. Play.

Details and screenshots: Guide › Install and start a project.

No email after 15 minutes? Look in spam, then write to support with the address you paid with.
